# V4.0.0 Portfolio Baseline

Baseline date: **August 6, 2026**

This release establishes the public engineering-alpha baseline for CAISO Market Intelligence.

## Publicly demonstrated

- FastAPI service and OpenAPI documentation;
- structured CAISO, EIA, and NRC research pathways;
- source-role, confidence, limitation, and evidence fields;
- clarification, hold, and research-required states;
- controlled and explicitly labelled web-research fallback;
- automated API and public-contract tests.

## Explicit boundaries

- not a trading or settlement system;
- not a replacement for licensed market-data services;
- no licensed premium data is bundled or redistributed;
- authentication, distributed rate limiting, production observability, and SLOs remain production-hardening work.

## Release gate

The repository is suitable for LinkedIn promotion as an **engineering alpha** after CI passes and repository security settings are enabled.
